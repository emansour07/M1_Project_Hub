ARX / M1

Local model health checks

Download M1 Model Checker v1 XML

Local pilot checkset. Prepared using Autodesk’s published Revit 2024 Model Checker XML definitions. Its structure has been validated; execution in the team’s installed Revit/Model Checker version must be verified on one representative model before production rollout. No paid checking, scheduled cloud jobs or model modifications are enabled.

Run locally

  1. Use a model copy corresponding to the exact ACC version being assessed. Record its ACC item link and version number. Do not upgrade or save over the source model for this check.
  2. Open it in its compatible Revit version, with Autodesk Interoperability Tools / Model Checker installed.
  3. Model Checker → Setup → Open the downloaded XML. Review the 19 checks. If the installed tool rejects a check, use its matching Configurator to review it; do not report unsupported checks as passing.
  4. Model Checker → Run. Review element lists and findings. The duplicate-element test can be slow and only covers the family-instance conditions encoded in the check; it is not an exhaustive geometric audit.
  5. Export the results locally. In M1 → Coordination & quality → Import & manage reports, choose Model QA/QC. Import a flat CSV/XLSX with one row per check. Use the blank CSV template if the exported report contains nested summary sections.
  6. Include a stable check ID, title, result, model filename, checked ACC version, asset, discipline, element IDs, finding and report date. Select the matching columns in the preview. Use Count / list for observations, Pass or Fail only for actual evaluated rules, and Not checked for unsupported or skipped checks.
  7. Use the same report register name when updating that model’s assessment. Check a new ACC model version again before treating the result as current.

Warnings, file size, largest families, model/detail groups, in-place familiesModel-health observations. No invented warning-count or file-size pass threshold.
Revit version, design options, phases, worksetsReview model setup and content. These do not independently establish compliance.
Project information and coordinatesInventory for review. Coordinate units and approved targets are not assumed; no zero-coordinate target is imposed.
Revit/CAD links and link pinning, levels and gridsInventory and review. No unapproved workset naming rule is imposed.
Imported CAD and duplicate modeled family instancesModel-hygiene findings for review against the M1 checklist. Correct findings in the authoring model.
Filename, fixed FXX parcel, asset code, required delivery formatsUse the dashboard’s existing naming and shared-folder Checker. These are separate from this native-model checkset.
Asset information and COBiePending the client query and confirmed parameter mapping. No fabricated compliance percentage. The default COBie template will be versioned when its mapping is agreed.
Civil 3D DWG / engineering design correctnessNot covered by a Revit checkset. Requires the corresponding discipline’s authoring-tool checks and engineering review.

Source and maintenance

Adapted from Autodesk’s published Revit 2024 check definitions. The root/Heading/Section/Check structure, built-in check types and filter conditions follow that source. M1 selection, observation labels and CAD finding message were prepared for this project. Revision v1, 17 November 2026.
